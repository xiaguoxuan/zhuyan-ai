# 住颜 AI：今日思考整理

> 日期：2026-06-08
> 状态：本地思考记录，未提交、未推送、未发布。

## 一、当前开发阶段

住颜 AI 已经走过基础功能开发阶段，当前处于：

```text
第 1 阶段：单房间价值验证
```

技术上已具备：

- 单房间软装设计；
- 四格 Concept 方案；
- A/B/C/D 选择；
- 正式 V1 版本；
- 参考风格和家具套系分析；
- 不可变版本和项目恢复；
- 独立图片找家具；
- 一图多家具识别；
- 同款合并、异款拆分；
- 可编辑购物清单；
- 淘宝、京东、1688、拼多多搜索入口；
- 图片权利确认和费用确认；
- 图片分析运行进度界面；
- 本地持久化和 revision 冲突保护。

当前重点不是继续堆功能，而是验证：

- 谁愿意使用；
- 谁愿意付费；
- 用户为什么结果付费；
- 用户是否真的会采购或改造；
- 用户是否会重复使用。

## 二、房地产 OPC 的 AI 方向

个人公司 OPC 不适合一开始做庞大的房地产平台，更适合把自己熟悉的一项房地产服务，变成可重复、可交付、可收费的 AI 工作流。

适合的方向包括：

1. 房源内容生产；
2. 房屋照片和软装焕新；
3. 出租房和包租房运营；
4. 图片找家具和采购辅助；
5. 房源资料整理和尽调辅助；
6. 租赁运营和房东助理；
7. 带看和客户跟进；
8. 房产视频和短视频运营；
9. 房屋维修和物业协同；
10. 房地产经营数据分析。

其中，最符合住颜 AI 当前基础的是：

```text
出租房 / 包租房软装焕新
+ 图片找家具
+ 采购清单
+ 多房间管理
```

## 三、住颜 AI 的建议定位

不建议定位为：

```text
AI 装修效果图生成器
```

建议逐步定位为：

> 面向房东、民宿经营者和软装从业者的 AI 房屋焕新与采购工作台。

核心不是生成一张图片，而是完成：

```text
房间照片
→ 理解空间约束
→ 选择风格
→ 形成软装方案
→ 保存版本
→ 识别家具
→ 生成采购清单
→ 搜索和采购
→ 继续修改
```

长期产品主线：

### 房屋焕新

```text
房间照片
→ 软装方案
→ 四格方向
→ 效果图
→ 多版本比较
```

### 家具采购

```text
参考图或房间图
→ 多件家具识别
→ 可编辑清单
→ 搜索词
→ 平台搜索
→ 购买状态
```

### 房屋运营

```text
项目
→ 房源
→ 房间
→ 采购
→ 维修
→ 版本
→ 交付
```

## 四、推广策略

当前不建议马上投广告或大规模推广。最适合的是：

> 小范围、低成本、人工陪跑式推广。

### 第一目标客户

优先选择出租房或包租房房东，尤其是：

- 手里有多套房；
- 房间照片效果不好；
- 想低成本焕新；
- 不想大装修；
- 需要快速出租；
- 不擅长软装和采购。

第二目标客户可以是：

- 小型软装设计师；
- 房产中介；
- 民宿经营者；
- 房屋托管公司。

### 推广时不要只说 AI

不建议只宣传：

```text
AI 装修效果图工具
```

建议宣传结果：

```text
上传出租房照片，快速得到低成本软装焕新方案和家具采购清单。
```

图片找家具可以单独作为入口：

```text
看到喜欢的室内图，自动拆出沙发、茶几、地毯、灯具等家具，生成逐件搜索清单。
```

核心价值表达：

```text
看得懂
买得到
改得动
能落地
```

## 五、早期体验产品

建议推出“单房间软装焕新诊断”：

- 1 张房间原图分析；
- 1 组四格方向方案；
- 1 张正式软装效果图；
- 1 份家具软装清单；
- 逐件搜索关键词；
- 保留项、替换项和优先级；
- 人工简单说明。

图片找家具体验版：

```text
上传一张室内图
→ 识别 5～15 件主要家具软装
→ 生成可编辑清单
→ 提供固定平台搜索入口
```

早期采用人工陪跑：

```text
用户联系
→ 了解房间情况
→ 上传照片
→ 确认使用权和费用
→ AI 生成
→ 人工检查
→ 交付结果
→ 收集反馈
```

## 六、前 30 天推广动作

### 第 1 周：准备

- 准备 3 个案例；
- 准备一页产品介绍；
- 制作 30 秒操作视频；
- 准备体验报名表；
- 准备反馈表和服务边界说明。

### 第 2 周：邀请体验用户

寻找 5～10 位房东或包租相关人员，邀请其提供真实房间照片和明确目标。

### 第 3 周：发布案例

发布：

- 原图和方案；
- 图片找家具过程；
- 清单编辑过程；
- 用户修改前后；
- 真实采购搜索过程。

### 第 4 周：小额付费体验

可尝试：

- 单房间体验方案；
- 图片找家具清单；
- 出租房软装焕新包。

具体价格应根据前 10 个用户反馈确定，不先凭空定价。

## 七、推广期间应记录的指标

不要只看阅读量和点赞量，要记录：

- 收到多少有效房间照片；
- 多少人完成权利确认；
- 多少人愿意等待生成；
- 多少人修改清单；
- 多少人点击平台搜索；
- 多少人重新打开清单；
- 多少人愿意推荐；
- 多少人愿意付费；
- 是否最终采购或改造。

核心判断：

> 用户是否从“看看效果图”走到“准备采购或改造”。

## 八、需要避免的事情

- 不要只做单次效果图 API 包装；
- 不要同时面向所有房地产人群；
- 不要过早购买 GPU 或自建重模型；
- 不要承诺真实同款、品牌、价格、库存或精确尺寸；
- 不要把 AI 结果当作产权、法律、估价或结构安全结论；
- 没有合规商品数据源前，不提供未经验证的具体商品详情页；
- 不要省略人工审核、用户确认和版本记录；
- 不要在没有真实用户反馈前大规模投放广告。

## 九、今日统一判断

住颜 AI 最值得优先验证的商业切入口是：

```text
出租房 / 包租房的低成本软装焕新
+ 图片找家具和采购清单
```

推广最有效的方式不是把产品发给很多人，而是：

> 找到一小批真实房东，陪他们把一套房间真正做完，并记录他们为什么愿意继续使用。

住颜 AI 的长期护城河不应是某一个模型，而应是：

```text
房地产场景知识
+ 房间和项目状态
+ 软装约束
+ 版本历史
+ 采购数据
+ 人工校正
+ 可交付工作流
```
